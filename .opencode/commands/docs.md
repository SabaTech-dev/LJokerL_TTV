# /docs

Actualiza documentación del proyecto según cambios recientes.

## Uso

```
/docs
```

## Funcionalidad

1. Analiza cambios recientes
2. Actualiza README.md
3. Actualiza ARCHITECTURE.md
4. Actualiza ROADMAP.md
5. Mantiene changelog

## Tipos de documentación

- README.md
- ARCHITECTURE.md
- ROADMAP.md
- Changelog
- API docs

## Agente asignado

**technical-writer** - Actualiza docs con GLM-5
