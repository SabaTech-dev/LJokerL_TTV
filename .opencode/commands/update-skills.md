# /update-skills

Actualiza el repositorio externo de skills a la última versión.

## Uso

```
/update-skills
```

## Funcionalidad

1. Ejecuta `git pull` en repositorio externo
2. Descarga últimas skills disponibles
3. Actualiza catálogo (860+ skills)
4. Notifica nuevas skills relevantes

## Agente asignado

**skill-manager** - Gestiona actualización de skills
