# Community Skills Reference

> **Source**: [sickn33/antigravity-awesome-skills](https://github.com/sickn33/antigravity-awesome-skills)

This directory acts as a reference for external "Community Skills" that can be adopted into this project.

## Highly Relevant Skills
The following skills identified in the registry are candidates for future import:

### Windows & PowerShell
*   `skills/powershell-windows`: Advanced PowerShell patterns.
*   `skills/windows-privilege-escalation`: Security testing for Windows environments.

### Quality & Security
*   `skills/code-review-checklist`: Standardized code review.
*   `skills/verification-before-completion`: Verification protocols (aligns with our `ui_verify.md`).
*   `skills/clean-code`: Best practices for maintainability.
*   `skills/cc-skill-security-review`: Security audit workflows.

### Automation
*   `skills/browser-automation`: Patterns for browser control (similar to our `ui_verify`).
*   `skills/github-workflow-automation`: CI/CD patterns.

## How to Use
To "install" one of these skills:
1.  Navigate to the GitHub repo.
2.  Copy the content of the skill's `SKILL.md`.
3.  Create a new directory in `.agent/skills/<skill_name>`.
4.  Paste the content into `.agent/skills/<skill_name>/SKILL.md`.
