                                  DIVIDER 4
-----------------------------------------------------------------------------

SILK Smoothness

SILK Smoothness is an old NVIDIA feature that tries smoothing out animations in games, higher the strength the stronger the smoothing but the higher the latency penalty. It does not work in every game, (Only DX11 & under) but the games it does work in the benefits are noticeable. Low or Medium is recommended if using it

It's not recommended to set "DisableUpdateCheck" to "false" because most updates do not require an exe recompile, which means the version number will read the same as previous versions even though the app as been updated, which means you will be told to update the program even if you're already on the latest version
