# 📖 Guía de Usuario - LJokerL_TTV Custom Config PRO v12.5

Bienvenido a la versión **12.5 "Next Gen"** de **LJokerL_TTV Custom Config PRO**. Esta herramienta ha sido diseñada para maximizar el rendimiento de tu PC, reducir la latencia de entrada y optimizar Windows 11 para gaming extremo y productividad profesional.

---

## 🚀 Centro de Control (WPF)

La suite ahora funciona con una **UI WPF nativa** llamada **LJokerL Control Center**. Desde ahí tienes todo integrado:

1.  **Perfiles**: Aplica o revierte perfiles base con un clic.
2.  **Monitoring**: Métricas en tiempo real (CPU/GPU/RAM/Disk/Net).
3.  **Benchmark**: Pruebas rápidas o completas con historial y comparación.
4.  **Logs**: Visor con búsqueda, filtros y exportación.

---

## 🛠️ Inicio Rápido

1.  **Ejecución**: Abre la app **LJokerL Control Center** (WPF).
2.  **Dashboard**: Selecciona perfil, tweaks avanzados, monitoring o benchmark.
3.  **Permisos**: Para aplicar cambios del sistema, se requieren privilegios de Administrador.
4.  **Uso**: Toda la interacción ocurre en la interfaz WPF.

## 🔧 Opciones Avanzadas

Accediendo mediante la tecla **[A]** en el menú principal:

*   **VBS & HVCI**: Detecta y desactiva la seguridad de virtualización de Windows (puede ganar hasta un 15% de FPS).
*   **Limpieza de Temporales**: Elimina archivos basura que ralentizan el sistema.
*   **Ping Servidores**: Herramienta para verificar latencia a servidores de juegos populares.
*   **Gestión de Recursos**: Descarga e integra herramientas externas recomendadas por LJokerL_TTV.

El monitoreo en tiempo real ahora está integrado en la app WPF:

*   **Auto Updater**: El sistema verifica automáticamente si hay nuevas versiones de la suite en nuestro repositorio oficial.

---

## ⚠️ Recomendaciones de Seguridad

1.  **Reinicio**: Siempre reinicia tu PC después de aplicar un perfil de optimización para que los cambios de Registro y Red surtan efecto.
2.  **Antivirus**: Algunos antivirus pueden detectar el script como sospechoso debido a los cambios en el registro. Es un falso positivo; puedes añadir la carpeta `C:\LJokerL_TTV` a exclusiones.
3.  **Laptop**: Si optimizas una laptop, asegúrate de estar conectado a la corriente para evitar que los perfiles de energía reduzcan el rendimiento.
